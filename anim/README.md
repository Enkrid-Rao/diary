# 宣传动画

一段 17 秒的产品动画：从标题起手，一个玻璃窗口浮现，侧栏按月分组滑入，编辑器逐字打出
Markdown，右侧预览同步渲染，块级公式淡入，最后收在 logo 与标语上。

---

## 一、方案选型

动画有三种主流做法，逐项对比后选了第三种。

| 方案 | 工作方式 | 优点 | 局限 | 本项目 |
| --- | --- | --- | --- | --- |
| **Lottie** | After Effects 导出 JSON，`lottie-web` 在页面里播放 | 体积只有几十 KB、纯矢量、任意缩放不糊、可交互 | 只产出 JSON 播放器，**不产出视频文件**；文字排版、公式、玻璃模糊都做不了；必须有 AE 源文件 | 不适用：本机没有 AE，也没有设计稿 |
| **Remotion** | React 组件即动画，时间轴驱动，直接渲染 MP4 | 数据驱动、可批量出片、生态成熟、产物即视频 | 需要 Node + React + 一整套依赖；商用按席位收费；为一个 17 秒短片引入构建链，与这个项目"零构建、零 node_modules"的气质直接冲突 | 不适用：杀鸡用牛刀 |
| **HTML/CSS 时间轴 + 无头浏览器逐帧 + ffmpeg** | 页面里写 `seek(t)`，把每一帧的状态算出来；用 CDP 逐帧截图；ffmpeg 编码 | 零额外依赖（Edge 自带、ffmpeg 单文件）；**能直接复用项目自己的设计令牌、字体和 KaTeX**；同一 `t` 永远得到同一帧，可复现 | 逐帧渲染慢（510 帧约 3 分钟）；动效要手写代码，没有时间轴软件可拖 | **采用** |

选它的三个理由：

1. **视觉一致性是硬指标**。片子里的 `--ink #07080c`、玻璃渐变、琥珀色 `#f0b46a`、
   JetBrains Mono、KaTeX 公式，全部来自 `static/style.css` 与 `static/vendor`，不是照着截图重画的。
   换成 Lottie 或 Remotion，都得把这些重新实现一遍，且做不出 `backdrop-filter` 的玻璃质感。
2. **不引入新工具链**。这个项目连 `node_modules` 都没有，为一段宣传片装 Node 不划算。
3. **可复现**。改一句文案、调一个时间点，重跑一条命令就出新片；不存在"源文件在某台机器上"的问题。

## 二、成品规格

| 项 | 值 |
| --- | --- |
| 文件 | `diary-promo.mp4` |
| 分辨率 | 1920 × 1080（16:9） |
| 帧率 | 30 fps，共 510 帧 |
| 时长 | 17.0 秒（末尾定格 0.8 秒） |
| 编码 | H.264 / yuv420p / CRF 18 / `+faststart` |
| 音轨 | 无（便于按平台需要叠加音乐） |
| 源文件 | `scene.html`（动画本体）、`render.py`（渲染脚本） |

## 三、文案

**标题**

> Diary

**标语**

> 每天写一点，公式也在里面

**说明文字**

> 本地优先的 Markdown 日记 —— 实时 LaTeX、全文搜索、玻璃日历、深浅双主题。
> 一天一个 `.md` 文件，不要账号，不走云端，没有遥测。

**片中字幕（依次出现）**

1. 一天一页 Markdown
2. LaTeX 边打边渲染
3. 全文搜索 Ctrl+F

**收尾署名**

> github.com/Enkrid-Rao/diary

## 四、视频简介

- **用途**：仓库首屏展示、Release 说明里的动图替代品、项目介绍页 hero、演示开场。
- **时长**：17 秒。前 3 秒完成"标题 + 窗口浮现"，不看后面也能记住是什么；19 秒以上在社交平台容易被划走。
- **风格**：暗色玻璃 + 琥珀强调，极光缓慢漂移，运动曲线统一用 ease-out-quint，没有弹跳和炫技；
  字幕克制、只留三行卖点。整体语气跟应用本身一致——安静、克制、可用。
- **适用场景**：
  - GitHub 仓库首页（MP4 可直接拖进 README，或转 GIF/WebP 预览）
  - 产品落地页首屏
  - B 站 / YouTube / 小红书 的 15 秒短片位
  - 演讲或录屏演示的开场片头

## 五、分镜

| 时间 | 画面 |
| --- | --- |
| 0.00 – 1.60 | 极光缓动；标题 `Diary` 字距由 52px 收到 22px 并上浮淡入，副标题与细线随后出现 |
| 1.60 – 3.00 | 标题退场；应用窗口从 `scale(0.935)` + 9px 模糊 + 下移 46px 浮现到正面 |
| 2.60 – 3.90 | 一道斜向高光从玻璃表面自左向右扫过 |
| 2.95 – 4.60 | 侧栏三个月份分组与七个条目依次从左侧滑入（每条错开 130ms） |
| 3.30 – 7.10 | 编辑器逐字打出 Markdown；右侧预览按「行完成」逐块同步出现 |
| 7.35 – 8.50 | 块级公式从 `scale(0.92)` + 模糊淡入 |
| 8.35 – 9.30 | 公式下方扫过一道琥珀下划线 |
| 8.90 – 14.10 | 三条字幕依次交叉淡入淡出 |
| 11.60 – 14.60 | 镜头缓慢推近（1.00 → 1.035） |
| 14.35 – 16.20 | 窗口虚化退场；logo、标题、标语、仓库地址依次浮现 |
| 16.20 – 17.00 | 定格 |

## 六、重新渲染

```bash
python anim/render.py                                    # 全片 17s / 30fps
python anim/render.py --from 0 --to 4 --fps 12 --out preview.mp4   # 只渲染一段试看
python anim/render.py --frames-only                      # 只出帧，不编码
```

依赖：系统自带的 Edge（用它的 CDP 逐帧截图）+ `imageio-ffmpeg`（`pip install imageio-ffmpeg`，
自带 ffmpeg 二进制，不需要单独装）。

渲染过程中间帧写在 `anim/frames/`，默认编码完成后删除；加 `--keep` 可保留。
