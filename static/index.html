常规

日记存放位置、自动保存与启动行为

文件与保存

日记目录 所有日记以 YYYY-MM-DD.md 存放于此；换目录只影响之后写入的位置，不会迁移已有文件
自动保存延迟 停止输入后多久写入磁盘
900 ms

启动与窗口

启动时打开 "上次编辑的日期"只在 90 天内有效，太久以前会自动回到今天
记住窗口大小与位置 下次启动按上次的窗口几何还原

主题

明暗 浅色为纸感底色；下面三种底色决定浅色下纸的冷暖
底色 整套背景底色与氛围光
强调色 标题、选区、按钮与高亮统一取色

质感

顶栏样式 融合：无边框，与页面连成一体；玻璃：悬浮的毛玻璃卡片
玻璃模糊强度 数值越高背景越朦胧，过低会显得扁平
30 px
环境光晕 背景缓慢流动的彩色光，关掉更省电
胶片颗粒 极淡的噪点，用来压住大面积渐变的塑料感
界面动效 弹层过渡、列表错峰入场、翻页位移；关掉后所有动画瞬时完成

字体

界面字体 侧栏、顶栏与面板用的字体，默认跟随编辑区
自定义界面字体 填本机已安装的字体名，可逗号分隔多个；前面的字体会先试

660 px

正文字号
14 px

编辑器字体 左侧编辑区（源码）用的字体，默认是 JetBrains Mono

布局

分栏比例 编辑区占工作区的宽度，也可以直接拖中间的分隔条
50 %
同步滚动 开启后两栏按内容位置对齐联动；关闭则各滚各的。左侧分栏把手亮起即为开启
Tab 宽度

输入辅助

自动配对符号 输入 ( [ { ' " ` $ 自动补另一半；在闭合符前再输入一次会跳过
回车延续列表 在 - 或 1. 结尾的行回车时自动补上下一个标记
显示行号 左侧加一列行号，写长文时便于定位

键位绑定

点右侧按键框后直接按下新的组合键；Esc 取消，Backspace 清除。若组合已被占用，原来的绑定会自动让出。

重置

恢复默认键位 只影响快捷键，其他设置保持不变
