# 旁白与配乐

成片 `diary-promo.mp4` 已经带音轨：十句旁白 + 一段合成配乐，全部由 `audio.py` 生成。
这份文档记录**实际做了什么**、为什么这么定，以及怎么改。

---

## 一、实际旁白（与成片逐句对齐）

## 二、为什么是十句，不是十二句

前一版方案按「每条字幕配一句」写成了 12 句，真正合成出来才发现放不下：

- 34.4 秒的画面里，从容的中文旁白语速约 4.4 字/秒，**全部人声最多约 28 秒**，
  剩下 6 秒要塞进 9 个句间气口，平均每句只能停 0.6 秒；
- 五条卖点字幕每条只停留 2 秒，若逐条念，一句话还没说完画面就切走了。

所以改成「字幕只上眼、旁白只点题」：字幕原样留在画面上，旁白不再复述，
把省下来的时间给开头和结尾。第 8、9 句各覆盖两条字幕，语气上是总结，不是报菜名。

## 三、声音是怎么做的

**旁白**

1. `edge-tts` 逐句合成，一句一个文件，缓存在 `voice/`；
2. 每句裁掉首尾多余静音（只留 45 ms 气口），否则微软音色句尾那半秒会把后面全推后；
3. 逐句响度对齐到 −22 dBFS RMS（增益限制在 ±6 dB 内，避免把气声抬起来）；
4. 按入点摆放，前一句没说完就顺延到它结束后 0.34 秒，绝不叠字；
5. 句首句尾各 8 ms 淡入淡出，去掉爆音。

**配乐**（没有用现成音源，全部合成，因此没有版权问题、长度天然对齐）

| 项 | 做法 |
| --- | --- |
| 和声 | Am9 → Fmaj7 → Cmaj7 → G6/9，四段各 8–9 秒，相邻交叠 2.2 秒 |
| 音色 | 每个音 = 基频 + 六个谐波（幅度按 1/h^1.8 衰减）+ 0.11 Hz 慢颤音 |
| 宽度 | 左右声道各偏 ±0.16%，同和弦不同相位，听起来是一整片而不是单声道加混响 |
| 点音 | 十颗很轻的钢琴音（指数衰减 + 轻微不谐和泛音），落在和弦音上，间隔 2.5–3.5 秒 |
| 空间 | 1.9 秒卷积混响（噪声乘指数衰减做脉冲响应），两声道用不同种子 |
| 收尾 | 最后 2.4 秒按平方曲线收干，和画面定格同时结束 |

**混音**

| 项 | 值 | 说明 |
| --- | --- | --- |
| 旁白电平 | 约 −20 dBFS | 说话段实测 |
| 音乐电平 | 约 −33 dBFS | 空档处，比旁白低 13 dB |
| 闪避 | 4 dB | 旁白一开口音乐下压，说完约 0.3 秒浮回 |
| 整体响度 | −18 LUFS | 静态增益，不做动态压缩 |
| 峰值 | −1.0 dBFS | 软限幅（只在超过 0.80 处压），AAC 编码后仍有余量 |

## 四、想改的话

文案、入点都在 `audio.py` 顶部的 `SEGMENTS` 里：一行 `(入点秒, "句子")`。
改完跑：

```bash
python anim/audio.py probe    # 先看每句实测时长，确认放得下、不撞车
python anim/audio.py build    # 合成并挂到 diary-promo.mp4
```

换音色改 `VOICE`，改语速改 `RATE`（例如 `+0%` 更利落，`-8%` 更慢）。可选的普通话音色：

| 音色 | 听感 |
| --- | --- |
| `zh-CN-YunxiNeural` | 年轻男声，温和，本片在用 |
| `zh-CN-YunyangNeural` | 新闻男声，端正但偏硬 |
| `zh-CN-XiaoxiaoNeural` | 通用女声，明亮 |
| `zh-CN-YunjianNeural` | 低沉男声，适合更慢的片子 |

试听一句：

```bash
edge-tts --voice zh-CN-YunyangNeural --text "日记，本该这么简单。" --write-media try.mp3
```

`voice/` 里的分句会缓存，改文案后要删掉对应文件（或整个目录）才会重新合成。

## 五、如果以后想换成真人配音

表格里的入点就是给配音员的节奏参考，录完按句切开，用 `adelay` 摆位即可：

```bash
ffmpeg -y -i s01.wav -i s02.wav -i s03.wav -i s04.wav -i s05.wav \
  -i s06.wav -i s07.wav -i s08.wav -i s09.wav -i s10.wav \
  -filter_complex "\
[0:a]adelay=500|500[a0];[1:a]adelay=3900|3900[a1];[2:a]adelay=6880|6880[a2];\
[3:a]adelay=11000|11000[a3];[4:a]adelay=15200|15200[a4];[5:a]adelay=19000|19000[a5];\
[6:a]adelay=22400|22400[a6];[7:a]adelay=25000|25000[a7];[8:a]adelay=28950|28950[a8];\
[9:a]adelay=31920|31920[a9];\
[a0][a1][a2][a3][a4][a5][a6][a7][a8][a9]amix=inputs=10:normalize=0[out]" \
  -map "[out]" narration.wav
```

然后把 `narration.wav` 当作旁白轨，用 `audio.py` 里同一个混音函数处理即可
（`build/` 下会留下 `music.wav`，配乐可以直接复用）。
