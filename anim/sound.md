# 声音

成片是**纯音乐**：34.4 秒的环境铺底，没有旁白。音乐不是从素材站下的，
是用 `audio.py` 按和弦进行合成出来的——长度天然等于画面，也没有授权问题。

---

## 一、配乐怎么写的

| 项 | 做法 |
| --- | --- |
| 和声 | Am9 → Fmaj7 → Cmaj7 → G6/9，四段各 8–9 秒，相邻交叠 2.2 秒 |
| 音色 | 每个音 = 基频 + 六个谐波（按 1/h^1.8 衰减）+ 0.11 Hz 慢颤音 |
| 宽度 | 左右声道各偏 ±1.6 音分、不同相位，是一片声场而不是单声道加混响 |
| 高频层 | 同组音的高八度泛音（只取 3–5 次谐波），9 秒起慢慢打开、24 秒最亮、32 秒收回 |
| 点音 | 十九颗很轻的钢琴音（指数衰减 + 轻微不谐和泛音），落在当前和弦音上 |
| 空间 | 2.2 秒卷积混响，两声道用不同噪声做脉冲响应；42 Hz 低切、7.6 kHz 高切 |
| 收尾 | 最后 2.4 秒按平方曲线收干，和画面定格同时结束 |

四段和弦的分界大致对应画面：Am9 铺开场与窗口浮现，Fmaj7 承接侧栏与打字，
Cmaj7 落在公式与「已保存」，G6/9 撑住五条字幕和收尾。

**全片的起伏**按画面写死了一条音量曲线，不是从头响到尾：

| 段落 | 相对电平 | 说明 |
| --- | --- | --- |
| 0 – 4s 开场 | −24.6 dBFS | 只留低频铺底，给标题让位 |
| 6 – 10s 窗口 | −21.9 dBFS | 高频层开始渗入 |
| 10 – 19s 打字 | −20.6 dBFS | 稳定在中段，点音跟着落笔的节奏出现 |
| 19 – 22s 公式 | −20.6 dBFS | 保持不变，让「已保存」那一下安静下来 |
| 22 – 32s 字幕 | −19.0 dBFS | 全片最满，五条卖点需要一点推动力 |
| 32 – 34.4s 收尾 | −28.2 dBFS | 收干，只剩余韵 |

整条 −16 LUFS、真峰值 −3.9 dBTP，AAC 编码后仍有余量，平台做响度归一化时不会忽大忽小。

## 二、怎么改

配乐全部在 `audio.py` 的 `make_music()` 里：

- **换和弦**：改 `chords`（MIDI 音高数组）和 `spans`（每段的起止秒数），两者要一一对应；
- **改密度**：改 `motif` 列表里的 `(时间, 音级, 音量)`，音级是当前和弦里的第几个音；
- **改起伏**：改 `swell = np.interp(t, [...], [...])` 里的关键点和增益；
- **改音色**：`pad_note()` 的 `h0/h1/tilt` 控制泛音范围与衰减斜率，`pluck()` 控制点音的衰减时间。

改完重跑，只会重算声音，画面不动：

```bash
python anim/audio.py build
```

`build/music.wav` 是纯配乐，`build/mix.wav` 是最终音轨，都可以单独拿去听。

## 三、如果以后要加旁白

代码里这条路留着：`audio.py` 顶部有十句文案与入点，跑 `build --voice` 就会合成语音、
按时间轴摆放、并让音乐在开口时自动下压 4 dB。

```bash
python anim/audio.py probe          # 先看每句实测时长，确认放得下、不撞车
python anim/audio.py build --voice  # 合成旁白 + 配乐 + 混音
```
